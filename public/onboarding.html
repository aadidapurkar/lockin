Thanks for using Lockin

Please pin the extension

Features

Lock a Tab in a Window - Alt + Shift + L or click the pinned extension.
Change shortcut @ chrome://extensions/shortcuts.
When the lock icon is green, nothing is locked.
When the lock icon is orange, you are locking some tab in some window.

Tab Limit - Set a total tab limit, if you try to exceed it, the newest tab will close. Set by clicking on the extension pin.

Site Bans - Whenever you try to visit a particular URL which contains a substring you banned, the tab will close, e.g a ban of "instagram.com" will close "https://instagram.com". Set/Remove by clicking on the extension pin.
